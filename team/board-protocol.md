# بروتوكول اللوحة الحية

اللوحة الحية هي **المصدر الوحيد** لحالة كل فيديو. التسليم بين الأقسام ما يُعتبر تم إلا إذا انعكس عليها.

## الكارت (سجل واحد لكل فيديو)
| الحقل | مثال |
|---|---|
| `id` | `v-2026-11-03-bir-alghaib` |
| `title` | بئر الغائب |
| `type` | قصة رعب / واقعية / غموض / فلوق / كتاب |
| `stage` | من الحالات تحت |
| `owner` | المسؤولة الحالية (حنين / لينا / ريما+غادة / شهد / سارة / ماجد) |
| `due` | `الثلاثاء 3 نوفمبر — 9:00 م` |
| `word_count` | 2,340 (للسكريبت) |
| `scores` | `{ريما: 8.4, غادة: 8.1}` |
| `approval` | رقم طلب الموافقة وحالته |
| `version` | يرجعه النظام بعد كل كتابة |
| `updated_at` | `الاثنين 2 نوفمبر — 4:15 م` |
| `log` | سطر لكل تغيير: مين، وش تغيّر، ومتى |

## الحالات بالترتيب
```
فكرة ← بانتظار اعتماد الفكرة ← كتابة ← عند النقاد (سكريبت) ← جاهز للتصوير
← تصوير ← مونتاج ← عند النقاد (مونتاج) ← بانتظار موافقة المالك
← بانتظار موافقة النشر ← منشور ← قياس اليوم السابع ← مغلق
```
- الحالة **«مُرجَع»** ممكن تتركب مع أي مرحلة: يرجع الكارت لنفس القسم، مع سبب ومكان الخطأ.
- ما يتنقل الكارت من مرحلة لمرحلة إلا بعد ما تكتمل قائمة «خلص» الخاصة بالمرحلة.

## قاعدة رقم الإصدار (`if_version`)
عشان ما يمسح تحديث تحديث ثاني:
1. **اقرأ** الكارت وخذ رقم الإصدار الحالي، مثلاً `version = 7`.
2. **اكتب** التحديث ومعه `if_version: 7`.
3. **لو رجع تعارض:** معناه أحد حدّث الكارت قبلك. اقرأ النسخة الجديدة، وادمج تغييرك عليها بدون ما تمسح تغيير غيرك، ثم أعد الكتابة برقم الإصدار الجديد.
4. **ممنوع الكتابة بدون `if_version`**، وممنوع الكتابة الإجبارية فوق نسخة أحدث.

## قاعدة التوقيت (12 ساعة)
- كل `updated_at` و`due` وسطر في `log` يُكتب بنظام **12 ساعة** وبتوقيت الرياض، مثل `8:00 ص` و`9:30 م`.
- الصيغة: `اليوم + التاريخ — الساعة:الدقائق ص/م`.
- ممنوع نظام 24 ساعة في أي مكان يقرؤه المالك.

## مين يحدّث وش
| الحدث | مين تحدّث | الحالة الجديدة |
|---|---|---|
| تقديم أفكار اليوم | حنين | فكرة ← بانتظار اعتماد الفكرة |
| اعتماد المالك | جمانة | كتابة (ومعها `owner = لينا`) |
| تسليم السكريبت | لينا | عند النقاد (سكريبت) |
| قرار المجلس | ريما أو غادة | جاهز للتصوير / مُرجَع |
| رفع المادة المصوّرة | جمانة | مونتاج |
| تسليم النسختين والشورتات | شهد | عند النقاد (مونتاج) |
| اعتماد النسخة | جمانة | بانتظار موافقة النشر |
| النشر بعد الموافقة | سارة | منشور |
| تقرير اليوم السابع | سارة | مغلق |

## الأمان
- اللوحة ما تحفظ أي كلمة سر ولا مفتاح ولا بيانات دفع.
- أي تغيير في إعدادات اللوحة نفسها، أو في مين يقدر يشوفها، يحتاج موافقة المالك.
