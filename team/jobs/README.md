# ملفات قسم التوظيف (حنان)

لكل شخص مجلد خاص:

```
team/jobs/candidates/[اسم-الشخص]/
├── profile.md          الملف المهني المستخرج من السيرة
├── log.csv             سجل الإرسال (يمنع التكرار)
└── reports/
    └── report-YYYY-MM-DD.md   تقرير آخر اليوم
```

- **ملف السيرة نفسه ما يُرفع على المستودع** (بيانات شخصية). يُحفظ في مجلد السير في قوقل درايف، وحنان ترفقه من هناك.
- أعمدة سجل الإرسال: `التاريخ,الشركة,المدينة,الوظيفة,الإيميل,مصدر الإيميل,رابط الإعلان,الحالة,ملاحظات`
- الحالة: مسودة / أُرسل / ردّ / مقابلة / رفض / مرتد.
