# قائمة «خلص» الإلزامية وبوابات الاعتماد

ما ينتقل أي عمل للمرحلة اللي بعده إلا إذا انطبقت عليه **كل** بنود قائمة «خلص» الخاصة بمرحلته. البند اللي ما ينطبق عليه يُكتب جنبه «لا ينطبق» مع السبب، وما يُترك فاضي.

- **+10 XP** لكل قائمة «خلص» تنجح فيها المرحلة، بعد ما يؤكدها المالك.
- **+15 XP** إذا وافق المالك على العمل **بدون أي تعديل**.

التفاصيل في [levels.md](levels.md).

---

## 1. «خلص» البحث (حنين)
- [ ] 3 أفكار اليوم جاهزة قبل 7:30 ص
- [ ] كل فكرة لها بطاقة كاملة، كل حقولها معبّأة
- [ ] رابطين مرجعيين على الأقل لكل فكرة
- [ ] من 2 إلى 3 مقاطع ناجحة مشابهة، مع أرقامها
- [ ] الفصل بين الحقيقة الموثّقة والرواية المتداولة
- [ ] ما فيه تشابه مع فيديو نُشر خلال آخر 90 يوم، أو فيه زاوية جديدة واضحة
- [ ] المخاطر مكتوبة: حساسية، خصوصية، حقوق

**🚪 بوابة 1: اعتماد الفكرة** — المالك يختار فكرة، أو يرفض الثلاث ويطلب بدائل.

---

## 2. «خلص» الكتابة (لينا)
- [ ] **عدد الكلمات المنطوقة ≥ 2,100**، ومكتوب في أول السكريبت
- [ ] ما فيه حشو ولا تكرار لتكبير العدد
- [ ] الخطاف جاهز لأول 3 ثوانٍ، ومعه بديلين
- [ ] 3 عناوين مقترحة، كل واحد أقل من 60 حرف
- [ ] 3 نقاط تحوّل على الأقل، وحلقة فضول كل 2–3 دقائق
- [ ] ذروة واضحة وخاتمة قوية
- [ ] المراجع في آخر السكريبت
- [ ] قائمة التصوير: المشاهد، الزوايا، الجمل، الأماكن
- [ ] 3 مقاطع مرشحة للشورتات
- [ ] التسليم قبل 9:00 م ليلة التصوير

**🚪 بوابة 2: مجلس النقاد (سكريبت)** — نتيجة 8.0 أو أكثر عند ريما وعند غادة، وما فيه معيار أقل من 6.

---

## 3. «خلص» النقد (ريما + غادة)
- [ ] تأكدنا من عدد الكلمات قبل أي تقييم
- [ ] كل وحدة قيّمت لحالها قبل ما تشوف درجة الثانية
- [ ] كل درجة معها دليل مكتوب
- [ ] أي 10 معها فحص كامل موثّق، بند بند
- [ ] كل نقطة ضعف معها مكانها (رقم السطر أو الثانية) والإصلاح المقترح
- [ ] الكارت محدّث في اللوحة الحية ومعه رقم الإصدار

---

## 4. «خلص» التصوير (المالك، وجمانة تجهّز)
- [ ] قائمة التصوير وصلت للمالك قبل يوم التصوير
- [ ] كل المشاهد واللقطات المطلوبة اتصورت
- [ ] الملفات مرفوعة بأسماء واضحة: `YYYY-MM-DD_اسم-الفيديو_مشهد-رقم`

---

## 5. «خلص» المونتاج (شهد)
- [ ] بطاقة هوية الفيديو مسجّلة في montage-log.md **قبل** البدء
- [ ] ما فيه أي تطابق مع آخر 5 قوالب
- [ ] النسخة A والنسخة B جاهزتين، ومدة كل وحدة **15 دقيقة فأكثر**
- [ ] 3 شورتات (9:16)، كل شورت بخطاف مستقل
- [ ] **ما فيه أي نص على الوجه**
- [ ] **ما فيه تصحيح ألوان آلي**
- [ ] مستوى الصوت ثابت، والكابتشن متزامن
- [ ] هوية القناة الثابتة موجودة: الشعار، وخط الكابتشن، وعلامة القناة
- [ ] الموسيقى والمؤثرات أصلية أو مرخّصة

**🚪 بوابة 3: مجلس النقاد (مونتاج)** — نفس شروط الاجتياز.

**🚪 بوابة 4: موافقة المالك على النسخة** — يختار A أو B، أو يطلب تعديلات.

---

## 6. «خلص» النشر (سارة)
- [ ] 3 عناوين، ووصف، وفصول زمنية، وتاقات، وهاشتاقات
- [ ] الصورة المصغرة جاهزة
- [ ] فحص المونيتايزيشن تم
- [ ] التوقيت المقترح مكتوب بنظام 12 ساعة
- [ ] طلب الموافقة اليدوي على النشر جاهز

**🚪 بوابة 5: موافقة المالك على النشر** — طلب منفصل لكل فيديو. ما فيه موافقة عامة.

---
