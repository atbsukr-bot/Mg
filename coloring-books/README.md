# مولّد كتب التلوين للأطفال (أمازون)

يولّد كل يوم كتاب تلوين جاهز للرفع على أمازون للنشر المباشر:
- ملف الداخل: ٦٤ صفحة، ٣٠ رسمة على وجه واحد، مقاس ٨٫٥ × ١١ إنش، بدون نزيف.
- ملف الغلاف الكامل (خلفي + كعب + أمامي) بالمقاس الصحيح للكعب.
- ملف بيانات صفحة البيع (العنوان، الوصف، الكلمات المفتاحية، الأقسام، السعر).

## تدوير المواضيع (يومياً بالترتيب)
حيوانات ← مركبات ← أميرات وحيوانات خيالية ← ديناصورات ← حروف ← أرقام وأشكال ← موسمي (الكريسماس في الشتاء)

## التشغيل
```
pip install reportlab pymupdf
python3 make_book.py --out output            # كتاب اليوم
python3 make_book.py --date 2026-12-01 --out output   # يوم محدد
python3 qa.py output_qa animals              # صفحة مراجعة بصرية
```

الرسومات كلها مرسومة بالبرمجة داخل المجلد `cb`، والخط «فريدوكا» برخصة مفتوحة (في مجلد `fonts`).
