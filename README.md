# مكاتب شركة Mg — محاكاة حيّة لسير العمل بين الأقسام

محاكاة مرئية تفاعلية لمكاتب الشركة: كل موظف في غرفة قسمه، ومشاريع الفيديو تنتقل بين الأقسام مرحلةً بعد مرحلة حتى تُنشر.

## التشغيل
افتح `index.html` في المتصفح مباشرة، فلا يحتاج إلى خادم أو تثبيت.

## خط سير الإنتاج
الإدارة (اعتماد الفكرة) ← كتابة المحتوى (السكربت) ← الإنتاج (التصوير) ← المونتاج ← التصميم (الصورة المصغرة) ← التسويق (النشر) ← 🚀 منشور.
قسم الدعم التقني يستقبل بلاغات من الأقسام الأخرى، ثم يعيدها إليها بعد إصلاحها.

## الإشارات المرئية
- **💡 تضيء لمبة المكتب** لحظة استلام الموظف للمهمة وبدء العمل عليها، مع وميض خفيف وتشغيل الشاشة.
- **⚫ تنطفئ اللمبة** عند إنهاء المهمة، أو عند خمول الموظف أو ابتعاده عن مكتبه (استراحة، اجتماع، مغادرة).
- **📁 ملف ملوّن وشريط تقدّم** على المكتب يبيّنان المهمة الحالية ونسبة إنجازها.
- **📦 التسليم:** عند انتهاء المرحلة يحمل الموظف الملف ويمشي إلى صندوق «الوارد» في القسم التالي. يظهر المسار خطاً متقطعاً بلون المشروع، وتتوهّج الغرفة المستقبِلة.
- **🛬 الاستلام:** يطير الملف من صندوق الوارد إلى مكتب أول موظف متاح في القسم، فتضيء لمبته.
- **لوحة خط الإنتاج** أعلى الصفحة تحرّك بطاقة كل مشروع إلى عمود مرحلته الجديدة.
- **🚀 النشر:** قصاصات احتفال، وزيادة عدّاد الفيديوهات المنشورة في الاستقبال.
- **وضع الليل:** تبقى الغرف الفارغة مظلمة وتظهر إضاءة المكاتب العاملة بوضوح.

## التفاعل
- **الموظف:** اضغط عليه لاستلام مهمة أو استئنافها، أو إيقافها (خمول)، أو «إنهاء وتسليم» فوراً، أو إرساله إلى استراحة أو اجتماع، أو إزالته.
- **القسم أو صندوق الوارد:** اضغط عليه لعرض الفريق والمهام المنتظرة.
- **💡 مشروع جديد:** يرسل فكرة إلى وارد الإدارة لتبدأ رحلتها.
- **أدوات أخرى:** إضافة موظف، وتصفية الموظفين حسب الحالة، والبحث، والتحكم في المحاكاة وسرعتها، والإضاءة (تلقائي/نهار/ليل).

تُحفظ البيانات في متصفحك، ويعيد زر ↺ البيانات الافتراضية.
