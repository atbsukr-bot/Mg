# قالب الصورة المصغرة

- `thumb3.html` + `thumb3.js`: **القالب المعتمد** على تصميم المالك المرجعي (`team/brand/thumbnail-reference.jpg`).
  - التشغيل: `node thumb3.js <اسم> "<السطر الأول>" "<السطر الثاني>" "<الشريط>" <صورة الدليل> [يسار الشخص] [أعلى] [عرض] [حجم الخط] [أعلى الشريط]`
  - يحتاج في نفس المجلد: `person.png` (الشخص مقصوص، 2560×1440)، و`bg3.jpg` (خلفية سوداء وحمراء)، و`logo.png`، و`Tajawal-Black.ttf`.
  - القص: نموذج فصل الشخص من ميديا بايب (selfie_multiclass_256x256)، ونحتفظ بأكبر كتلة بس.
- `thumb.html` + `thumb.js`: النسخة الأولى (قبل المرجع)، للأرشيف.
